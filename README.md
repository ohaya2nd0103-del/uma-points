# うまポイント

**[アプリを開く](https://ohaya2nd0103-del.github.io/uma-points/)**

iPhoneのSafariで開き、共有 →「ホーム画面に追加」で使えます。架空ポイント・換金不可の競馬シミュレーションです。

## 内蔵の年間カレンダー

中央・地方を共通の年間カレンダーにまとめ、月・開催週・競馬場・クラス・重賞格で探せます。

- 中央重賞130競走：GⅠ24、GⅡ38、GⅢ68。
- 地方ダートグレード46競走：GⅠ1、JpnⅠ12、JpnⅡ12、JpnⅢ21。
- 地域独自の重賞299競走を追加。NAR公式2026年一覧掲載の地方重賞は計345競走・15場です。
- S・SP・H・M・BG・重賞Ⅰ/Ⅱなどの格を、そのまま表示します。ばんえい27重賞も収録。
- 新馬106・未勝利175などを含む、計1,871レース・51週枠。
- G・JpnのⅠは青、Ⅱは赤紫、Ⅲは緑。地域独自の重賞は紫で表示します。

締切時刻の入力・時刻による購入制限・精算の待機はありません。内蔵レースから直接買い目を選べます。開催日・番号は自動で設定し、必要な場合は別途編集できます。開催週は年間の目安です。

購入・精算・保存・分析に対応し、時刻なしのレースも開催日で集計します。精算済みの開催への追加購入は防ぎ、同じ番組を再度使うときは別の開催レコードを作成します。

中央の週枠・一般競走には[参考番組表](https://ds2.yublog.com/info/race_program.php)の公開データを使用。元資料は画像転記で、公式との全件照合は未実施です。地方345競走の名称・格・場・距離は[NAR公式2026年一覧](https://www.keiba.go.jp/gradedrace/schedule_2026.html)から取り込み、同年の日程を月・週の目安に配置しています。年齢を確定できない行は不明としています。地域独自の格をG・Jpnに換算しません。JBCの場・距離は2026年の金沢開催です。開催日や開催場が毎年同じになる保証はありません。出典の詳細はアプリの設定から確認できます。

## 保存と更新

初期元本10,000 pt、翌月から月3,000 pt。購入・精算・履歴は端末内のIndexedDBに保存し、GitHubへ送信しません。既存データを初期化せず更新します。古い画面のままなら、設定の「更新して再読み込み」を使ってください。

現金・実際の投票・換金・課金はありません。Web版のバックグラウンド通知・触覚はありません。iPhone Safari実機は未検証です。
