# うまポイント

[アプリを開く](https://ohaya2nd0103-del.github.io/uma-points/)

iPhoneのSafariで開き、共有 →「ホーム画面に追加」で使えます。架空ポイント・換金不可。現金・実際の投票・課金はありません。

## ダビスタ2参考のカレンダー

Nintendo Switch 2版の攻略サイトの番組表を参考に、月・週・競馬場・クラスで探せます。1,539番組に新馬106件・未勝利175件、1〜3勝クラス、OP・重賞を含みます。

[参考番組表](https://ds2.yublog.com/info/race_program.php)と同ページの公開JSONから番組の事実項目だけを取り込みました。確認日2026年11月8日、画像転記データ版2026-10-09.v3。元メタデータではゲーム名・版は未特定とされており、公式との完全一致・網羅性は保証しません。画像やサイトの文章・UIは同梱していません。

ゲームの月・週を実日付に変換せず、番組を選んでアプリ内の開催日・番号・購入締切を設定します。新馬でも購入・精算・保存・分析へ進めます。購入・残高・既存履歴は初期化せず維持します。旧画面のままなら設定から「更新して再読み込み」を使ってください。サイトデータの削除は不要です。

## ポイントと保存

初期元本10,000 pt、翌月から月3,000 pt。払戻は倍率によるシミュレーションで1 pt未満切り捨て。購入・精算・履歴は端末内のIndexedDBに保存し、GitHubへ送信しません。ブラウザーのサイトデータを消すと復元できません。

Web版にバックグラウンド通知・触覚はありません。写真保存は共有メニューまたはPNG出力です。iOS Safari実機は未検証です。
