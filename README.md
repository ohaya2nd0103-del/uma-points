# うまポイント

[アプリを開く](https://ohaya2nd0103-del.github.io/uma-points/)

iPhoneのSafariで開き、共有メニュー →「ホーム画面に追加」→「追加」で使えます。現金・実際の投票・換金・課金はありません。

ポイント管理・購入予定・長押し購入・紙馬券・精算下書き・差額修正・履歴・分析を、端末内のIndexedDBで保存します。初期元本10,000 pt、翌月から月3,000 pt。払戻は倍率によるシミュレーションで、1 pt未満を切り捨てます。

購入・履歴のデータはGitHubへ送信しません。アプリのソースは公開されています。ブラウザーのサイトデータを消すと復元できません。継続利用するホーム画面アイコンから使用してください。

Web版ではバックグラウンドの発走10分前通知と触覚はありません。画像保存は共有メニューまたはPNGダウンロードです。iOS Safari実機・ホーム画面追加後の動作は未検証です。

公式データは2026年第5回東京競馬の確認済み重賞5競走のみ。発走時刻・頭数・発売券種は未登録で、時刻補完と手動レース登録を用意しています。一般競走・地方・海外・2027年度の個別レースは未収録です。

[検証記録](TEST_REPORT.md) · [開発用ソース一式](source.zip)

公開版はビルド不要のHTML/CSS/JavaScriptです。開発用ソース一式には詳細README、50件のNodeテスト、実IndexedDBの9項目の検証ページ、開発サーバー、GitHub Actionsのテスト定義を含めています。テスト定義は開発用ZIP内です。
